You will build a self-contained data-visualisation web application using D3.js v6, placing all output files (HTML, JS, CSS, data) under /root/output/. Follow the d3-visualization skill's workflow: first load data, then render chart, next add interactivity, generate table, and link, and finally export.

Using D3.js (v6), visualize the input data stored at `/root/data/stock-descriptions.csv` and `/root/data/indiv-stock/`, return the output as `/root/output/index.html`, and generate `/root/output/js/d3.v6.min.js`, `/root/output/js/visualization.js`, and `/root/output/css/style.css`, plus `/root/output/data/` where you copy the provided input data.

**Base requirements (mandatory for all variants):** First, build a bubble chart where each bubble maps to one stock, sized by market capitalization (ETFs sized uniformly) and colored by sector, positioned by D3 force simulation with forceX/forceY clustering per sector, with forceCollide to prevent overlap. Each bubble is labeled with its ticker symbol inside and shows a hover tooltip with ticker, name, sector (no tooltip for ETFs), and the chart has a legend as a `<div>` element. Then add a data table listing all 50 stocks with "Ticker symbol", "Full company name", "Sector", "Market cap" (formatted, e.g. "1.64T"). Next, set up bidirectional linking: clicking a bubble highlights the table row, and clicking a table row highlights the bubble. Keep in mind `** All SVG <circle> elements must represent individual stock bubbles only. **` and `** Legend must be implemented as a div element. **`

**Additional chart (stacked below the bubble chart):** Finally, add a **treemap** with two levels: Sector → Company. The top-level rectangles = sectors (sized by total sector market cap), and the sub-rectangles = individual companies (sized by market cap). Label each company with its ticker and color it by sector, add a hover tooltip showing company name and market cap, and make clicking a company in the treemap highlight its bubble and table row.
